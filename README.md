# 卡厄思战斗采集器

用于记录一场战斗的开场、已加载配置和结算操作历史，供离线分析。**目前为试用版，已做离线检查，尚未完成新采集器的首次游戏实测。**

## 下载与使用

Windows x64 免安装包在 [Releases](https://github.com/slyzhydt/czn-battle-collector/releases)。请选择 `czn-battle-collector-0.1.0-preview.zip`，不是 GitHub 自动生成的源码压缩包。

1. 解压整个工具包，双击 **启动采集.cmd**。
2. 正常进入战斗，等开幕效果结束、手牌出现，暂不出牌或结束回合。
3. 在工具中选 **1 记录新开场**，填写模式、角色和语言。
4. 显示读取完成并断开后，正常打完整场；失败也请保留。
5. 出现结算界面后先不点继续、领取或复活，切回工具选 **2 记录结算并导出**。
6. 将 `exports` 中对应 ZIP 交给收集人。不要把战斗数据上传到本仓库或 Issue。

首次先由一人采一场并确认能重放，再安排多人批量采集。完整说明见 [使用说明.txt](使用说明.txt)。

## 范围与限制

- 只支持 `profile.json` 指定的 PC 客户端及资源版本；不同版本会在连接前停止。
- 读取战斗工作表、已加载配置和有限现有缓存。没有抓包、代理、证书安装、自动打牌或主动加载未加载资源。
- 开场、结算分别短暂连接，完成后释放读取代码并断开；恢复回执不确定时须保持工具窗口打开，正常退出游戏。
- 原始数据保存在本机，没有自动上传。记录包含时间、阵容、打法及随机采集者编号，不应当作完全匿名数据。
- 开场预先划分训练组与留出组，同版本同种子同关卡的重试归同组。配对完成不代表已能训练，仍需资源核对与整场重放。
- 单次读取上限 1 MiB；不完整或超限会停止，不静默截断。其他模式和新角色尚不能保证完整覆盖。

本仓库仅包含采集器；不包含战斗模拟器、搜索算法、模型、训练集、原始战斗快照或游戏资源。

## 源码运行与打包

源码运行需要 Windows x64、Python 3.11，以及 `requirements.txt` 中的依赖。

```powershell
python -m pip install -r requirements.txt
python -B collector.py --self-check
python -B collector.py
```

只想使用工具请下载免安装包。源码依赖由开发者自行安装，程序不会自动安装依赖或提权。

在装有完整 Python 3.11 的 Windows 环境中生成本地运行包：

```powershell
python -B build_portable.py dist/collector
```

生成位置为 `dist/collector/battle-collector`；打包程序不联网，也不连接游戏。它需要本地 Python 的标准库、DLL 和依赖许可文件。

## 检查与权限

`python -m unittest discover -s tests -v` 检查采集器边界与数据配对，不连接游戏。`VALIDATION.json` 记录此前离线验证范围；这些检查不替代实机验收。

仓库初始为私有，仅所有者管理；不自动邀请协作者。自动检查使用只读仓库权限，代码检出依赖固定到提交。主分支保护需要在 GitHub 设置中实际启用，配置说明本身不代表已生效；以仓库设置及交付回读结果为准。

运行包校验值见 `SHA256SUMS`；依赖及许可见 `THIRD_PARTY.txt` 和运行包内许可文件。
